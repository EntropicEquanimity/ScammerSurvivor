## Recording notes

- Real phone, held or on a stand, screen recording from the phone itself. No desktop browser.
- Start from the lock screen every take. The first notification must land inside the first five seconds, so load the quick day before pressing record, then lock the phone.
- Record a backup take of the call with a different pack. If the call screen reports no beats, skip the call in that take and use the backup.
- English voice-over, English captions burned in. Captions carry the model names in full: Gemini 3.8 Flash, Gemini 3.8 Flash TTS, Vertex AI.
- No real names, numbers or faces. The people chips are the only names on screen.
- The agent graph is a deck graphic exported as an image; cut to it, do not screen-record the deck.
- Under 2:50. Trim shot 25 first if it runs long.
- Publish on YouTube (unlisted is fine) or Drive. Open the link in a private window before pasting it into the README and the dashboard.
- Nothing said about the live voice caller, Scout or Translator. None is in this build.
- Room mode is in the build (`#room`) but not in this cut; the About shot (25) passes its row on screen. If the cut runs short, a five-second shot of the facilitator board, ids and counts only, fits between shots 23 and 24.
